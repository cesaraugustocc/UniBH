# Projetos UniBH

Repositório destinado aos projetos, exercícios e atividades desenvolvidos durante minha graduação em Ciência da Computação na UniBH.

## Projetos

### 01 - Estruturas de Decisão e Seleção 
Conjunto de exercícios desenvolvidos em Java para praticar estruturas de decisão (if, else if, else) e selecao (switch case).

### 02 - Estruturas de Repetição
Conjunto de exercícios desenvolvidos em Java para praticar estruturas de repetição.

### 03 - Mosaico do Castelo
Atividade desenvolvida em Java.

### 04 - Vetores
Conjunto de exercícios desenvolvidos em Java para praticar Vetores.
